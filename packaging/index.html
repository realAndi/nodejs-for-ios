nodejs-for-ios

An APT repository — add it in Sileo.
…

Provides Node.js with npm, npx and working nvm, for jailbroken iOS. The package page is a native depiction your package manager renders itself; the write-up is on GitHub.

The package is about 20 KB. Node itself is downloaded from nodejs.org when you install, verified against the checksum this build pinned, and patched for iOS on the device.
